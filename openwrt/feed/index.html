infinite-streaming-boa packages

Signed package feeds for boa, the per-device link conditioner: an apt repository for Raspberry Pi OS and Debian, and an apk feed for OpenWrt.

Raspberry Pi OS and Debian (apt)

Version@DEBVERSION@
Architecturesarm64 (Raspberry Pi OS 64-bit), amd64
Packageinfinite-streaming-boa
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://jonathaneoliver.github.io/infinite-streaming-boa/apt/boa-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/infinite-streaming-boa.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/infinite-streaming-boa.gpg] https://jonathaneoliver.github.io/infinite-streaming-boa/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/infinite-streaming-boa.list
sudo apt update
sudo apt install infinite-streaming-boa

The package installs the daemon and its service, and pulls in hostapd, iw, nftables and iperf3. It does not build the bridge or configure the radios: the service is enabled, and starts once the br-lan bridge exists. Set the ports in /etc/default/infinite-streaming-boa. Later releases arrive with apt upgrade. For a box that does all of that for you, flash the Pi image instead.

OpenWrt (apk)

Version@VERSION@
OpenWrt@RELEASE@
Architecture@ARCH@ (Raspberry Pi 5, and routers of the same architecture)
Packagesboa, luci-app-boa

Before installing

boa conditions traffic on a transparent bridge, and needs the full hostapd. Neither is something a package should do to a router on its own, so they are done by hand, once:

  • The uplink port, wired ports and access points in br-lan; lan on DHCP; OpenWrt's DHCP and RA off; wan removed.
  • wpad-mbedtls in place of wpad-basic-mbedtls, with 802.11k/v on each access point.

The OpenWrt README has the exact commands.

Install

wget -O /etc/apk/keys/boa-packages.pem \
  https://jonathaneoliver.github.io/infinite-streaming-boa/openwrt/boa-packages.pem
echo https://jonathaneoliver.github.io/infinite-streaming-boa/openwrt/@RELEASE@/@ARCH@/packages.adb \
  >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add luci-app-boa

Then run boa-setup check: it is read-only, and lists what the device still needs, with the command that fixes each item. After that, open LuCI → Services → infinite-streaming-boa, or http://<device>:8080/. Later releases arrive with apk upgrade, or from LuCI → System → Software.

Trust

Both are signed: apt checks the repository's InRelease against the keyring named in signed-by, and apk checks the feed's index against the key in /etc/apk/keys, so neither needs its signature checks turned off. Each key signs nothing but its own feed.
